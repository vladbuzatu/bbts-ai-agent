# Trend radar

Current design signals, with sources. **Trends are signals, not instructions.** Use at
most one or two that genuinely fit the brand and the users. Refreshed quarterly by the
knowledge curator (owner approves). Last reviewed: 2026-11.

| Signal | What it looks like | Use when | Avoid / caveats |
|---|---|---|---|
| **Intent over decoration** | Calmer pages, fewer elements, every element earns its place; a reaction to AI-made sameness | Almost always: it's the baseline expectation in 2026 | "Minimal" is not the same as "empty". Still needs a point of view and a signature element |
| **Bold, expressive typography** | Large, characterful type as the main visual, with variable fonts and distinctive families | Brand and marketing pages; headings in apps | Body text stays highly readable. Watch long Romanian words at large sizes |
| **Raw, visible structure** | Schematic, grid-forward, "honest" layouts that show their structure; tactile or brutalist textures in premium brands | Data-heavy tools (inventory, dashboards); brands that want to feel direct and trustworthy | Don't turn into the generic "newspaper hairlines" look; structure must encode information |
| **Bento / modular grids** | Dashboard-like tiles of different sizes for an overview | Overview and dashboard screens with mixed content | Not for every page; tiles of equal size become the "identical cards" default |
| **Purposeful micro-motion, with an off switch** | Motion that confirms actions and shows change; users can reduce or stop it | Feedback on save, discard and import progress | No decorative entrance animations everywhere; always respect reduced motion |
| **Single dominant brand colour / monochrome + one accent** | One owned colour used confidently (orange is popular right now) | Brands that need recognition in a crowded market | Colour must never be the only signal for status; check contrast |
| **Human touch** | Hand-made illustration, custom icons, imperfect textures | Consumer-facing and local businesses | Must be custom and consistent, never stock "illustration packs" |
| **Glass / translucency ("liquid glass")** | Translucent layered surfaces with highlights | Sparingly, for overlays on rich backgrounds | Easily fails contrast. Never behind body text |
| **Dark mode as a real theme** | A designed dark palette, not inverted colours | Apps used for long periods or in dim places | Design and test both themes; semantic tokens make this cheap |
