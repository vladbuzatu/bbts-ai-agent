# Lessons learned

problem in this project. Keep it short: when a lesson becomes a permanent rule,
move it into the right playbook in `.claude/skills/` and delete it here.

```
## L-001 · YYYY-MM-DD · area (frontend | backend | tests | design | deploy | process)

- Rule: one line, imperative ("Always…", "Never…")
```
